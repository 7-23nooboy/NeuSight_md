# NeuSight DeepMD 预测器精度验证报告 (v2 — Overhead 模型修复后)

**测试日期**: 2026-04-03
**测试环境**: NVIDIA H100 NVL (95GB), DeepMD-kit 3.1.3, PyTorch 2.10.0+cu128
**Device Config**: NVIDIA_H100_80GB_HBM3

---

## 修复内容

**Bug**: v1 overhead 模型使用 `wall = max(cpu_pipeline, gpu_pipeline)` 公式，
由于 cpu_pipeline 是常量 (~6.56ms) 且永远大于 gpu_pipeline，
导致所有原子数的预测结果完全相同 (6.7117ms)。

**修复**: v2 改用两区间模型:
- `fixed_overhead` = 固定 CPU dispatch 开销 (不随原子数变化)
- `unmodeled_compute` = 未建模 GPU 操作 (power law, 随原子数超线性增长)
- `e2e = max(fixed_overhead, mlp_compute + unmodeled_compute)`

## 4. 模型分析

### Overhead-bound 区间 (32-1024 atoms)
- Water: 预测 6.05ms vs 实测 5.6-5.9ms → 系统性高估 ~5%
- Copper: 预测 4.85ms vs 实测 4.4-4.8ms → 系统性高估 ~6%
- 原因: fixed overhead 校准值略偏高 (来自之前一轮 benchmark 数据)
- 可优化: 多轮 benchmark 取中位数，或动态校准

### Compute-bound 区间 (2048+ atoms)
- Water 2048: 预测 11.86ms vs 实测 11.74ms → 误差仅 +1.0%
- Water 4096: 预测 35.48ms vs 实测 35.24ms → 误差仅 +0.7%
- Power law 拟合非常准确 (beta=1.708)

### Per-type 校准
- Water (2 types): fixed = 3.5 + 2×1.2 = 5.9ms → 略高于实测 5.6-5.7ms
- Copper (1 type): fixed = 3.5 + 1×1.2 = 4.7ms → 略高于实测 4.4-4.5ms
- 差异 ~1.2ms/type 的校准是准确的
